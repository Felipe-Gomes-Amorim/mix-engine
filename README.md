# SNES Asset Editor

Ferramenta web (React + TypeScript) para importar/converter assets e montar
fases de um jogo de plataforma SNES. Consumida junto com o projeto irmão da
engine em C: `../jogo-plataforma-snes`.

Ver `CLAUDE.md` para escopo e convenções, e `docs/DATA_FORMAT.md` para o
contrato de dados com a engine.

## Rodando localmente

```bash
npm install
npm run dev      # dev server
npm run build    # type-check + build de produção
npm run lint      # oxlint
```
